# Моя школа — образовательное PWA для ребёнка 7 лет

Один ребёнок (1 класс, билингва рус/нем), Хромбук с сенсорным экраном. Модули: математика, русский, немецкий.
Чистые HTML/CSS/JS (ES-модули), без фреймворков, сборщика, внешних зависимостей и сетевых запросов. Общаться с владельцем по-русски.

## Как запустить

Нужен любой локальный статический сервер из корня проекта, например:

```bash
python -m http.server 8080
```

Открыть http://localhost:8080/ в Chrome. Service worker работает только на `localhost` или https, поэтому `file://` не подходит.
После первого открытия приложение работает офлайн и устанавливается на полку Хромбука (меню Chrome → «Установить»).
Файлы отдаются сетью в первую очередь, кэш — только запасной вариант, поэтому правки видны сразу после перезагрузки.

## Структура

```
index.html, manifest.webmanifest, sw.js, icons/
core/                  ядро (модули его не импортируют)
  main.js              запуск, переключение экранов, запуск модуля, награды
  registry.js          чтение modules/registry.json и manifest.json, import() модуля, кэширование
  context.js           сборка ctx для модуля
  speech.js            speak(): audio/<язык>/<ключ>.mp3 → Web Speech API
  sounds.js            мягкие звуки (WebAudio)
  rewards.js           звёзды за серию, стикеры, пороги
  storage.js           настройки и прогресс (localStorage), экспорт/импорт JSON
  strings.js           ВСЕ тексты интерфейса ядра
  dom.js               h(), onTap(), button()
  screens/             menu, result, stickers, parent
  styles/              base.css, screens.css
modules/
  registry.json        список id модулей (одна строка на модуль)
  <id>/manifest.json, index.js, style.css, texts.js …
audio/ru/, audio/de/   необязательные озвучки <ключ>.mp3
```

## Контракт модуля

`modules/<id>/manifest.json`: `id` (= имя папки), `title`, `subject` (`math` | `orientation` | `russian` | `german` | `english`), `icon` (эмодзи или файл в папке модуля), `description`, `version`.
Необязательно: `challenge` (только у `modules/challenge`: разделы сложных заданий, см. ниже), `styles` (список css), `files` (остальные файлы модуля и аудио — чтобы они попали в офлайн-кэш), `cycle` (id круга, см. ниже), `voice: true` (включить озвучку только для этого модуля, даже если глобально она выключена).

`modules/<id>/index.js` экспортирует `start(ctx)`. Функция должна вернуться быстро (не ждать конца серии) и может вернуть функцию очистки. `ctx`:

| Поле | Назначение |
|---|---|
| `container` | DOM-корень модуля |
| `voice` | `true`, если озвучка включена (`core/config.js`). При `false` `speak()` ничего не произносит, но «длится» как речь; модуль скрывает кнопку «повторить» |
| `speak(text, lang, key?)` | озвучка, `lang` — `'ru'` или `'de'`; Promise по окончании речи. Файл: `audio/<lang>/<key>.mp3`; без `key` ключ строится из текста |
| `sound(name)` | `tap`, `correct`, `hint`, `star`, `done` |
| `settings` | `{ seriesLength, speechRate, volume }`, только чтение |
| `hard` | ключи «трудных» заданий этого модуля из прошлых серий, только чтение |
| `finish({ correct, total, mistakes })` | конец серии; `mistakes` — `[{ key, label }]`. Звёзды, прогресс и экран результата делает ядро |

## Круги и супер-наклейки

Модули с одинаковым `cycle` в манифесте образуют круг. Сейчас пять кругов (**правило: у каждого модуля любого раздела, кроме `english`, есть `cycle`** — `check.mjs` это проверяет): `orientation` (`left-right`, `left-right-other`), `math` (вся математика: `addition-10`, `addition-20`, `subtraction-10`, `subtraction-20`, `compare-numbers`, `word-problems`, `money`), `russian` (`reading-ru`, `reading-phrases`, `reading-sentences`, `reading-pick`, `reading-long`) и `german` (`reading-de`, `reading-phrases-de`, `reading-sentences-de`, `reading-pick-de`, `reading-long-de`). Супер-наклейки всех кругов копятся в одной общей сказке.
Завершённая серия закрывает кнопку модуля (серая плитка с ✓), остальные остаются доступны в любом порядке.
Когда пройдены все включённые модули круга, ядро выдаёт супер-наклейку, открывает все кнопки, и круг начинается заново (`core/cycles.js`).
Модули без `cycle` (сейчас только раздел English) доступны всегда. Закрытый модуль нельзя повторить, в том числе кнопкой «Ещё раз». Модуль, выключенный родителем, в круг не входит.
Если все доступные модули круга оказались пройдены (родитель отключил непройденный), круг молча начинается заново без награды (`healCycles`), чтобы кнопки не застряли закрытыми. Прежние круги `arithmetic` и `numbers` при чтении сохранения сливаются в `math` (`CYCLE_ALIASES` в `core/storage.js`).
Прогресс круга и число супер-наклеек хранятся в `localStorage` вместе с остальным прогрессом.
Супер-наклейки собираются в **мирах** (`WORLDS` в `core/rewards.js`): «Моя сказка» (единорог, принцесса, замок, диван…), «Подводный мир» (русалки), «Волшебный лес», «Сладкая страна». Каждый мир — сцена с 12 предметами (положение, размер, названия на русском и немецком заданы в данных). Когда мир собран, открывается следующий; после последнего миры повторяются, лишние наклейки лежат отдельным рядом. При получении на экране результата вылетает окно с поздравлением («Ты получила «Русалка»! Твой подводный мир растёт.»), а при завершении мира — сообщение о новом мире.

## Правила для новых модулей

- Добавление модуля = папка `modules/<id>/` + одна строка в `modules/registry.json`. Файлы `core/` не правим.
- Из `core/` ничего не импортировать — только `ctx`. Свои файлы модуль импортирует относительными путями.
- Задания генерируются кодом, не фиксированным списком. Ошибочные задания повторяются в конце серии.
- `correct` — ответы с первой попытки. Ошибка = мягкая подсказка и ещё одна попытка; никаких красных крестов и грустных звуков.
- В каждом задании есть кнопка «повторить» (повторный вызов `speak`); при `ctx.voice === false` она скрыта (`repeatBtn.hidden = !ctx.voice`).
- Тексты модуля — в `modules/<id>/texts.js`, не разбросаны по коду. Немецкий раздел целиком по-немецки (тексты, заголовок плитки, озвучка).
- Модуль не обращается к сети и не использует внешние библиотеки, шрифты, картинки по URL.
- Ключи `hard`/`mistakes` должны быть стабильными и разбираемыми обратно (например, `3+4`).
- Свои стили — с префиксом модуля (`.a10-…`), чтобы не пересекаться с другими модулями и ядром.

## Требования к детскому интерфейсу

- Сенсорное управление через Pointer Events. Цели касания не меньше 64 px (лучше 100+ для основных ответов). Никаких `:hover`.
- Перетаскивание пальцем там, где оно уместно; обычное касание должно работать всегда. Клавиатура (Enter/Пробел) — запасной вариант (`click` с `detail === 0`).
- Во время игры нет прокрутки и зума: `touch-action: none`, `overflow: hidden`.
- Ландшафт, всё помещается на экран 1280×720 без прокрутки. Размеры в `vh`/`vw`/`clamp()`.
- Крупные шрифты, минимум текста, смысл передаётся картинками и голосом.
- Кнопка «домой» (🏠) рисуется ядром слева сверху; у `container` боковые поля 96 px — не занимайте их.
- Тон позитивный: поощрение вместо оценки, мягкие звуки.
- Никакой рекламы, регистрации, аналитики и отправки данных.

## Ядро: что важно помнить

- Новый файл в `core/` нужно дописать в `CORE_FILES` в `sw.js`, иначе он не попадёт в офлайн-кэш при первой установке.
- Разделы меню сейчас: математика, право и лево (`orientation`), русский язык, Deutsch. Немецкий раздел устроен как русский: `reading-de`, `reading-phrases-de` и `reading-sentences-de` — копии русских модулей со своими словарями (`words.js`, `data.js`), текстами по-немецки и озвучкой `'de'`. Прилагательное в `reading-phrases-de` — без артикля (grüner Hund, grüne Katze, grünes Haus).
- Новый предмет — запись в `STR.subjects` и `STR.subjectOrder` в `core/strings.js` (поле `lang` — язык служебных текстов ребёнку).
- Все тексты ядра — только в `core/strings.js`.
- Прогресс лежит в `localStorage` под ключом `school-app-v1`; экспорт/импорт — на экране для родителя.
- «Трудное» задание забывается после 3 серий, в которых оно было предложено и решено без ошибки. Каждой серии ядро даёт модулю до 2 самых частых трудных заданий (`ctx.hard`) и отмечает их как предложенные.
- Звёзды: ≥90% верных — 3, ≥70% — 2, иначе 1 (`starsFor` в `core/rewards.js`). Звёзды — валюта: в магазине (вкладка «Магазин» на экране «Наклейки») ребёнок сам покупает наклейки. Каталог — 9 альбомов по 12–24 наклейки, всего 120 (`ALBUMS`): цены 5 (первый альбом), 6, 10, 14 и 20 звёзд по редкости. На счету = заработано (`stars`) − потрачено (`spent`). Купленные наклейки (`owned`) хранятся вместе с прогрессом. Прежний прогресс переносится при первом запуске: за каждые 5 звёзд до 24 наклеек считаются купленными.
- Озвучка целиком включается и выключается флагом `VOICE_ENABLED` в `core/config.js`; отдельному модулю её включает `"voice": true` в манифесте (так сделан раздел English) (сейчас `false`: звука речи нет, настройки голоса у родителя скрыты). Остальные звуки (`sound`) работают.
- Голос синтеза для `ru` и `de` родитель выбирает на экране «Родителям» (список голосов браузера, онлайн-голоса помечены); по умолчанию — автоподбор в `core/speech.js`. Без интернета онлайн-голос заменяется локальным.
- Скорость речи (`speechRate`) применяется к синтезу; mp3-файлы воспроизводятся как записаны.

## Усложнённые упражнения по чтению (русский)

Два модуля для ребёнка, который уже уверенно читает; входят в круг `russian` (круг теперь из пяти модулей). Оба без озвучки, как и весь русский раздел. Прежние три модуля остались как лёгкая основа. Третий вариант («Собери слово из букв») владелец отклонил как слишком простой и убрал. Немецкие копии — `reading-pick-de` («Lesen und Bild finden») и `reading-long-de` («Lange Sätze»), круг `german`; устроены так же, но берут слова и предложения из немецких модулей, озвучка `'de'`.

- `reading-pick` («Читаем и ищем картинку»): показано слово / два слова / предложение, нужно выбрать картинку из 3–4. Уровни: слово до 5 букв (3 картинки) → слово до 8 букв (4, похожие по написанию) → «красный кот» (тонированные эмодзи, как в `reading-phrases`) → предложение (act/place, две эмодзи в карточке). Ключи трудных: `w:кот`, `p:red:кот`, `s:Кот пьёт молоко`. Данные берёт из соседних модулей (`../reading-ru/words.js`, `../reading-phrases/data.js`, `../reading-sentences/data.js`) — это исключение из правила «модуль самодостаточен», как у `english-quiz`; файлы перечислены в `files` манифеста.
- `reading-long` («Длинные предложения»): копия механики `reading-sentences` (собрать предложение из слов), но 5–6 слов. `data.js` строит предложения кодом из `../reading-sentences/data.js`: `two` («Кот пьёт молоко и спит»), `adj` («Весёлый кот спит на мягком диване»; прилагательные согласованы по роду героя и падежу места, не про цвет), `pair` («Кот и собака спят на траве»). Лишние слова верхнего уровня — не тот род/падеж/число или спорят с картинкой. Родов героев (`GENDER`) и форм прилагательных к местам (`PLACE_ADJ`) в `data.js` должно хватать на все герои и места из `reading-sentences`, иначе предложение молча пропускается.
- `reading-long-de` («Lange Sätze»): 6 слов. `two` («Die Katze trinkt Milch und schläft»), `adj` («Der große Hund läuft im Wald»: после артикля прилагательное на -e во всех трёх родах, лишнее слово — форма на -n; цвета не используются), `pair` («Hund und Katze spielen im Garten»; лишнее слово — глагол в единственном числе). Тексты на немецком, кроме комментариев в коде.

## Сложные задания, косточки и собака

**Косточка 🦴** — вторая валюта. Её дают только за сложное задание; тратится она на собак, корм и пакетики (экран собаки).

### Сложные задания (`core/challenges.js`, модуль `modules/challenge`)
- Каждые **25 заработанных звёзд** (всего заработано, `storage.stars()`, а не остаток после покупок наклеек) в случайном разделе появляется сложное задание. Звёзды, заработанные до появления этой возможности, не учитываются (при первом запуске `milestone` = текущие звёзды / 25). **Первые три задания выдаются сразу** (в трёх разных случайных разделах), чтобы хватило косточек на первую собаку.
- В разделе висит **не больше одного** задания. Если свободных разделов нет, задание ждёт (`owed`) и появится, когда раздел освободится. Раздел, где родитель выключил все модули, задание не получает.
- Задание — особая золотая плитка с 🦴 первой в своём разделе (`challengeTile` в `core/screens/menu.js`); пройдено — плитка исчезает. Вне кругов и супер-наклеек, звёзд не даёт, в статистику родителя и список модулей не попадает (в `app.manifests` его нет, оно лежит отдельно в `app.challenge`). В родительском разделе для заданий ничего нет.
- Прохождение: текст 3–4 предложения остаётся на экране, **один вопрос**, 3–4 варианта. Ошибка = мягкая подсказка (подсвечивается нужное предложение), ещё попытка; косточка за любое прохождение. После — экран «Косточка!» с кнопками «К собаке» / «В меню» (`renderChallengeResult`, язык раздела: русский или немецкий). На экране результата обычной серии, где появилось новое задание, показывается подсказка «Появилось сложное задание: …».
- Состояние в `storage.challenges()`: `ready`, `milestone`, `owed`, `pending` (`{ раздел: { seed } }`), `used` (пройденные тексты по разделам). `seed` фиксирует задание: если выйти и вернуться, текст тот же. `core/challenges.js`: `syncChallenges(app)` (вызывается при показе меню и после каждой серии), `challengeInfo`, `completeChallenge`.
- Модуль `modules/challenge` один на все разделы: манифест с полем `challenge.subjects` (название и значок плитки каждого раздела, `voice: true` у английского), `ctx.challenge = { subject, seed, used }`. Задания по разделам:
  - **русский** (`pools/ru.js`, 14 рассказов) и **немецкий** (`pools/de.js`, 14, всё по-немецки): рассказ и вопрос «кто / где / сколько / что»; у каждого `answer` (номер верного), `clue` (подсвечиваемое предложение);
  - **математика** (`pools/math.js`): задача-история в 3 предложения, два действия, числа до 20, 6 шаблонов (подарили-отдали, две коробки, покупка и сдача, возраст, страницы, ступеньки), склонения через `plural`;
  - **право и лево** (`pools/orientation.js`): «четыре зверя на скамейке» (кто справа/слева, кто с краю) и «куда улетела пчёлка» (где она относительно улья);
  - **английский** (`pools/en.json`, 12 рассказов): рассказ из 3 предложений слушается голосом Sonia (`audio/en/ch-<id>-story.mp3` и `-q.mp3`, делает `tools/make_audio.py`), ответ — картинка, цвет или число; английский текст на экране, перевод — при включённом переводе у родителя.
- Новый рассказ: добавить запись в пул (русский/немецкий/английский), для английского запустить `python tools/make_audio.py`; `node tools/check.mjs` проверяет число предложений, варианты, номер верного, подсветку, озвучку и прогоняет генераторы математики и «право-лево» на 400 зерен.

### Собака (`core/screens/dog.js`)
- Значок 🐶 с числом косточек на счету — справа вверху на главном экране (`dogButton` в `core/screens/menu.js`) → экран собаки (`app.go.dog`, `screenKind = 'dog'`; лимит времени действует как в меню).
- Экран собаки: слева двор, справа косточки, кнопки и магазин; выбор собаки — слева картинка, справа порода, цвет, имя (готовых имён 6), возраст (0 — щенок … 15; картинка меняется: щенок меньше, 10+ — седая мордочка). Рисунок собирается кодом как SVG (`drawDog` в `core/dogs.js`), внешних картинок нет.
- Цены: первая собака — 3 косточки (`DOG_PRICES` в `core/dogs.js`); цены 3, 5, 10 косточек по порядку покупки (если разрешить больше трёх собак, дальше +5: 15, 20, 25…); всего собак до 3 — на столько мест во дворе.
- Живая собака: части SVG (`dog-tail`, `dog-body`, `dog-head`, `dog-eyes`, `dog-tongue`) анимируются в `core/styles/dog.css` — виляет хвостом, дышит, моргает, наклоняет голову, высовывает язык; при `prefers-reduced-motion` анимации отключаются. Касание собаки — она подпрыгивает, вылетают сердечки.
- **Экран собаки всегда без прокрутки** (проверено на 1024×600, 1280×720, 1366×768; `overflow-y: auto` у `.dog-content` — только запасной вариант для очень низкого окна). Новые элементы на этом экране нужно проверять на то, что `scrollHeight` ≤ `clientHeight`.
- **Все купленные собаки стоят во дворе вместе** (до 3; размер зависит от числа); новая добавляется к прежним и становится выбранной. Собака выбирается касанием (метка ▼ над именем, касание ещё и гладит); корм и уборка действуют на выбранную. `id` собаки уникален.
- Двор: кнопки «Покормить» и «Убрать» со счётчиками, магазин: **1 🦴 = 5 банок корма**, **1 🦴 = 5 пакетиков** (`PACK_PRICE`, `FOOD_PACK`, `BAG_PACK` в `core/dogs.js`). Покормить: тратится банка, собака ест (2,6 с, «Ням-ням!»), потом «делает дела» (1,5 с) и во дворе падает какашка 💩 (`dog.poops` растёт сразу, на экране появляется после анимации). Убрать: касание на какашке или кнопка «Убрать», тратится пакетик. Больше `MAX_POOPS` = 4 какашек у одной собаки не бывает — пока их не уберут, кормить её нельзя («Сначала убери за собакой!»). Нет корма / пакетиков — подсказка со ссылкой на магазин.
- **Два набора данных о собаках: рабочий и тестовый.** Рабочий (в корне состояния: `bones`, `bonesSpent`, `dogs`, `food`, `bags`) — для ребёнка, на главном экране. Тестовый (`state.test`, та же форма) — для проверки новых возможностей: в разделе для родителя карточка «Тестовая собака» открывает тот же экран собаки (`app.go.dogTest()`, `renderDog(app, { scope: 'test' })`) со своими собаками и косточками, с панелью «ТЕСТ +1 🦴 / +5 🦴 / Сбросить тест» в шапке; «Назад» возвращает на экран родителя без проверки для взрослых. Наборы друг с другом не связаны; тестовый не сбрасывается кнопкой «Сбросить прогресс».
- Хранение (`core/storage.js`): `storage.dogApi('real' | 'test')` возвращает `bones()`, `bonesBalance()`, `addBones()`, `dogs()`, `buyDog()`, `food()`, `bags()`, `buyFood()`, `buyBags()`, `feedDog()`, `cleanPoop()` и `reset()` (сбрасывает только тестовый набор). Короткие `storage.bones/addBones/bonesBalance` — рабочие (меню, сложные задания). `dog` = `{ id, name, breed, color, age, poops }`, проверяются `cleanDog`. Состояние также хранит `challenges` и `dogsVersion`; экспорт/импорт их учитывают.
- **Одноразовый сброс старых тестовых собак:** без `dogsVersion: 2` (сохранения прототипа) при чтении рабочие косточки, собаки, корм, пакетики и сложные задания обнуляются (звёзды, наклейки, круги не трогаются), чтобы рабочий экран ребёнка начался с нуля; тестовый набор при этом пуст. Импорт старого файла прогресса тоже сбрасывает рабочих собак. Если изменится формат данных о собаках — увеличить `DOGS_VERSION` только осознанно: он стирает рабочих собак у всех.
- **Показатели собаки** (`dog.fed/mood/dirt/energy`, 0–100; пересчёт `applyDecay` при каждом обращении к `dogs()`, за отсутствие считается не больше 12 часов): сытость −0,17/мин, настроение −0,1/мин (быстрее, если голодна или грязная), грязь +0,07/мин, бодрость −0,1/мин. Показываются четырьмя полосками. Голодная собака (`HUNGRY_AT` 25) не играет в бегающие игры, уставшая (`TIRED_AT` 20) — тоже. Наказаний нет: собака просто просит внимания (значки 🍖 😢 🧼 над именем, мордочка, прикрытые глаза).
- **Вкладки справа** (6, без прокрутки): Уход (покормить, убрать, помыть, спать), Играть, Учёба, Наряды, Дом, Магазин. Мини-игры — отдельные файлы `core/dog/*.js`, каждый экспортирует `create…Game({ app, store, dog, alive, wait, exit })` → `{ el, cleanup }`, экран на весь `main`:
  `ball.js` (принеси мяч), `wash.js` (мытьё: шампунь 🧴, 3 штуки за 1 🦴, нужно оттереть пятна), `tricks.js` (сидеть, лапу, голос → крутись → танцуй; навык 0–5, выучено с 3), `hide.js` (прятки «горячо/холодно»), `walk.js` (прогулка), `quiz.js` (собака задаёт ребёнку 5 вопросов), `reading.js` (читаем вместе, угощение за каждые 3 верных), `album.js` (фотоальбом), `sleep.js` (сон).
  Игры тратят бодрость (`ENERGY_COST`), мелкие занятия слегка повышают настроение.
- **Наряды и обстановка** (`core/dog-items.js`): каталог `ITEMS` (кепки, короны, очки, ошейники, украшения; будки, лежанки, игрушки, растения, «затеи»), цены 1–6 🦴, куплено навсегда (`items` в наборе), надевание/расстановка бесплатны. Наряд у каждой собаки свой (`dog.outfit` = `{ hat, glasses, collar, extra }`) и рисуется в `drawDog`; обстановка общая для двора (`decor` = `{ house, bed, toy, plant, fun }`), эмодзи стоят позади собак (`DECOR_POSITIONS` в `core/dog/album.js`). Касание вещи — купить и надеть, повторное — снять. Если лежанка стоит, сон даёт больше настроения.
- **Фотоальбом:** кнопка «Фото» (вкладка «Дом») сохраняет снимок двора (собаки с нарядами и обстановка; хранятся данные, а не картинки; `photos`, не больше 12, `renderScene` в `core/dog/album.js` рисует снимок заново). «Альбом» — сетка снимков 6×2, касание увеличивает, «Удалить».
- **Сон:** «Спать» (бодрость ниже `SLEEP_FROM` 70, иначе «ещё не хочет спать») — ребёнок выключает свет, ночь, звёзды, Zzz, через 5 с бодрость 100, настроение +6 (+12 с лежанкой).
- **Рост и щенки** (по реальному времени): каждые `BIRTHDAY_DAYS` = 4 дня собаке +1 год до `GROW_MAX_AGE` = 6 (день рождения; поздравление показывается один раз через `store.takeNews()`, поле `dog.party`). Когда две взрослые (≥ `ADULT_AGE` 2) собаки живут вдвоём `PUPPY_DAYS` = 5 дней и обе в хорошем настроении, рождается щенок (порода и цвет от родителей, имя из `NAMES`, бесплатно; занимает третье место во дворе, поэтому третью собаку за 10 🦴 после этого не купить). Тестовый экран: кнопка «+4 дня» перематывает время (`store.shiftTime`).
- Данные набора (рабочего и тестового): `bones, bonesSpent, dogs, food, bags, shampoo, items, decor, photos, together, news`. `dog` = `{ id, name, breed, color, age, poops, fed, mood, dirt, energy, grew, party, updated, outfit, tricks }`. API `dogApi(scope)` кроме перечисленного выше: `shampoo/buyShampoo/washDog`, `adjust(id, {fed,mood,dirt,energy})`, `practiceTrick`, `items/decor/buyItem/equip/place`, `photos/addPhoto/deletePhoto`, `sleepDog`, `takeNews`, `shiftTime` (только тест). Старые сохранения читаются без сброса: недостающие поля получают значения по умолчанию (`DOGS_VERSION` не менялся).
- **Вкладка «Учёба» (квиз, чтение вместе) пока только на тестовом экране** (`testOnly: true` в `TABS` в `core/screens/dog.js`); у ребёнка 5 вкладок. Чтобы включить, убрать `testOnly`.
- **Лимит игр:** вкладка «Играть» (мяч, трюки, прятки, прогулка) — не больше `PLAY_LIMIT_SEC` = 180 с в день (`dogApi.playUsed/addPlay`, поле `play: { day, sec }` в наборе; новый день — с нуля). Время считается, пока идёт игра; когда набегает лимит, игра заканчивается окном «Время игр на сегодня вышло!»; на вкладке видно «ещё M:SS». На тестовом экране лимита нет. Мяч в «Принеси мяч» рисуется стилями (`.ball-art`), эмодзи 🎾 на Windows выглядит как ракетка.
- Файлы ядра: `core/dogs.js`, `core/dog-items.js`, `core/dog/*.js`, `core/challenges.js`, `core/screens/dog.js`, `core/styles/dog.css` — перечислены в `CORE_FILES` (`sw.js`) и подключены в `index.html`.

## Право и лево

Раздел `orientation`, круг `orientation` из двух модулей: пройденный закрывается, когда пройдены оба — супер-наклейка и круг заново.

- `left-right` («Право и лево»): только пчёлка на сетке 3×3 (прежние уровни — предмет слева/справа, ряды, пчёлка в ряду из 5 клеток — убраны по просьбе владельца). Показаны команды ⬅ ➡ ⬆ ⬇, пчёлка в клетке, нужно нажать клетку, куда она придёт (озвучка: налево, направо, вверх, вниз). Старт в случайной клетке, за край не выходит. Уровни — длина пути, не меньше 5 команд: 5 → 5–6 → 6–7. Подсказка после ошибки показывает, где лево и право, и пересказывает команды. Ключ задания — клетка старта и команды, например `4-LDR` (поэтому «трудное» повторяется точно таким же и в конце серии ошибочные задания даются теми же). Старые ключи прежних типов (`side`, `walk`…) в `ctx.hard` игнорируются.
- `left-right-other` («Лево и право другого»): человек стоит лицом к ребёнку — его правая рука там, где у ребёнка левая. Типы: «В какой руке у мамы мяч?» (ответ кнопками «в левой»/«в правой») и «Покажи правую руку папы» (нажать на руку рядом с человеком), каждый — когда человек стоит лицом к ребёнку (`face`) и когда спиной (`back`, чёрный силуэт). Уровни: `hold-face` → + `hand-face` → + спиной → всё вместе. После ошибки под заданием появляется объяснение словами (`hintFace`/`hintBack` в `texts.js`), после двух ошибок верный ответ подсвечивается. Ключи трудных: `hold-face`, `hand-face`, `hold-back`, `hand-back`. Герои и предметы — в `texts.js`.

## English и озвучка mp3

- Раздел `english`. Ребёнок английский не знает, поэтому здесь нужен звук. Озвучка включена только в модулях с `"voice": true`, остальные разделы без звука. Голос везде один: Sonia (британский английский, `en-GB-SoniaNeural`).
- Сейчас есть модуль `english-words` («Hello! Знакомство»): 17 тем (Animals, Colours, Numbers, Numbers 11–20, Family, Food, Fruit & veg, Body, Toys, School, Clothes, Weather, Home, Transport, Actions, Feelings, Nature), 178 слов → страницы по 4 карточки; слова проговариваются сами, касание карточки повторяет. Это знакомство, без проверок и без звёзд. Слова и картинки лежат в `modules/english-words/words.json` (эмодзи, цветные кружки, числа; все картинки в файле разные, иначе в тесте два одинаковых варианта; в теме не меньше 4 слов), озвучка — `audio/en/<слово>.mp3` (около 2 МБ). Плитки тем компактные: в модулях нет прокрутки, поэтому при добавлении тем проверяйте, что они помещаются на экран 1024×600 (сейчас 17 плиток в 4 ряда занимают 478 из 600 px; больше примерно 24 тем уже не поместятся). Перевод под словами показывается, если родитель включил его на экране «Родителям» (`ctx.settings.translation`, по умолчанию выключен).
- Модуль `english-quiz` («Hello! Угадай слово») — проверка знаний: звучит слово голосом Sonia, нужно выбрать картинку. Сначала выбирается тема (или «Mix» — все слова). Уровни: 0 — 3 картинки из разных тем, 1 — 3 из одной темы, 2–3 — 4 из одной темы; уровень растёт после двух верных подряд и падает после ошибки. После ошибки под картинками появляются слова и слово звучит снова, после второй ошибки верная картинка подсвечивается. Ошибочные слова повторяются в конце серии и попадают в «трудные» (`ctx.hard`), за серию даются звёзды. В круг не входит (`cycle` нет): английский раздел пока не образует круг.
- Исключение из правила «модуль самодостаточен»: `english-quiz` читает слова из `modules/english-words/words.json` (`../english-words/words.json`), чтобы список слов и озвучка были в одном месте. Файл перечислен в `files` манифеста, поэтому работает офлайн.
- Модуль `english-phrases` («Hello! Два слова») — аналог русского «Читаем два слова», но на слух: звучит «red cat», нужно выбрать картинку (эмодзи раскрашивается в цвет, как в русском модуле). Цвета (7) и предметы (24) выбираются списком в `modules/english-phrases/phrases.json` из `english-words/words.json` (у предмета должен быть эмодзи, у цвета — hex); озвучка — каждое сочетание отдельным файлом `audio/en/red-cat.mp3` (168 файлов). Уровни: 0 — отличаются предметы (цвет один), 1 — отличаются цвета (предмет один), 2–3 — 4 картинки, отличаются и цвет, и предмет. Ключ трудного задания — `red:cat`.
- Модуль `english-sentences` («Hello! Слушаем предложения») — слушаем простое предложение и выбираем картинку (две эмодзи: кто и что делает / с чем / где). 94 предложения лежат готовым списком в `modules/english-sentences/sentences.json` (`kind`: `do` «The cat sleeps.», `act` «The cat drinks milk.», `place` «The cat is on the sofa.», `feel` «The boy is happy.»; `en`, `ru`, `scene`), озвучка — `audio/en/the-cat-sleeps.mp3` (ключ из текста). Русский перевод под предложением показывается при включённой «подсказке-переводе» у родителя. Уровни: 0 — do и feel, 1 — act, 2 — place, 3 — всё вместе; с уровня 2 неверные картинки отличаются от верной только героем или действием. У двух предложений одного типа не должно быть одинаковой пары эмодзи (`check.mjs` это проверяет). Ключ трудного задания — сам текст предложения. Оба модуля без `cycle`.
- Файлы озвучки едут на Хромбук вместе с приложением (GitHub Pages и service worker). Чтобы работать офлайн, они перечислены в `files` манифеста (`../../audio/en/…`).
- Добавили слова в `words.json` — запустите `python tools/make_audio.py` (и `node tools/check.mjs` — он проверяет повторы картинок, озвучку и списки файлов): он создаст недостающие mp3 (пакет `edge-tts`, голоса Microsoft, интернет нужен только при создании) и обновит `files` в манифестах всех четырёх английских модулей. Скрипт озвучивает и слова, и сочетания «цвет + предмет» (`phrases.json`), и предложения (`sentences.json`) — после правки любого из трёх файлов запускайте его снова. Если pip ругается на сертификат: `pip install --use-feature=truststore edge-tts truststore` (сначала поставить `truststore`).

## Время в приложении и дневной лимит

- `core/main.js` раз в 5 секунд добавляет время в `usage` (секунды по дням, ключ — местная дата `ГГГГ-ММ-ДД`, `storage.addUsage`). Считается только когда вкладка видна и последнее касание было меньше 90 секунд назад. Экран для родителей и экран отдыха время не считают.
- Статистика на экране «Родителям» («Время в приложении»): сегодня, 7 и 30 дней со средним, список по дням за 30 дней со столбиками. Хранится 400 дней, экспортируется вместе с прогрессом.
- Дневной лимит (`settings.dailyLimit`, минуты, 0 — без ограничения; шаги 15/20/30/45/60/90/120/180). Когда время вышло, на меню, наклейках и при запуске модуля показывается экран `core/screens/limit.js` («На сегодня достаточно!») с кнопкой «Родителям». Если лимит вышел посреди задания, его дают закончить: блокировка наступает через 5 минут сверх лимита (`GRACE_MIN`) или когда ребёнок выходит в меню. Утром, в новый день, блокировка снимается сама.
- Когда время вышло, родитель на экране «Родителям» в блоке «Время на сегодня» нажимает «Ещё 15 минут», «Начать лимит заново» или «Снять лимит на сегодня» — это дополнительные минуты на текущий день (`storage.setBonus`, лимит на сегодня = `todayLimit()`), поэтому статистика времени остаётся точной, а завтра действует обычный лимит. Пока ничего не нажато, «Назад» снова ведёт на экран отдыха.
- Вход на экран «Родителям» (из меню и с экрана отдыха) закрыт проверкой «только для взрослых» (`core/screens/gate.js`): нужно решить пример на умножение (6–9 × 6–9) цифрами на экране или клавиатуре; при ошибке новый пример, после 3 ошибок подряд пауза 30 секунд. Перерисовка самого экрана родителя (после кнопок на нём) проверку не повторяет. Это защита от случайных входов, не от подросшего ребёнка, который выучил таблицу умножения.

## Проверка проекта

`node tools/check.mjs` — быстрая проверка без браузера: синтаксис, импорты, манифесты и реестр, офлайн-кэш (`sw.js`, поле `files`), опасные паттерны, а также банки русского и немецкого (повторы слов и картинок в `words.js` — они там тихо отбрасываются, повторы предметов в `data.js`, одинаковые предложения и повтор слова внутри предложения). Запускайте перед отправкой на GitHub; при ошибках скрипт перечисляет их с путями.

Размер банков: слов для чтения — русский 219, немецкий 195; предметов для «двух слов» — 65 и 68; предложений — 641 и 699 (основная часть — «X и Y …»). Новые слова и предложения дописываются в списки (`PAIRS`, `NOUNS`, `SUBJECTS`); у одного героя на одну картинку-место или картинку-предмет — одно действие, иначе предложения с одинаковой картинкой станут неоднозначными. Слова для чтения — до 10 букв, предметы для «двух слов» — до 7.
